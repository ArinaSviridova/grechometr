# Грехометр

Маленькая offline-first PWA, которая локально считает грехи, показывает прогресс до условного ада, распределяет баллы по кругам Данте и предлагает молитвы и искупления.

## Что уже реализовано

- Выбор персонажа: `girl` или `boy`.
- 10 визуальных уровней от ангела до демона.
- 10 динамических фонов, которые меняются вместе с уровнем.
- Каталог встроенных грехов и создание собственных.
- Для каждого типа греха: категория, базовая тяжесть 1-10 и вариант искупления.
- При совершении греха выбирается интенсивность 1-5.
- Формула баллов: `тяжесть × коэффициент интенсивности`.
- Коэффициенты: 0.25, 0.5, 1, 1.5, 2.
- 666 эффективных баллов = 100% пути к аду.
- Искупление уменьшает вклад конкретной записи на 40%, но не удаляет её из истории.
- Главный грех, текущий круг ада, статистика за сегодня и за всё время.
- 9 карточек кругов ада.
- Молитва дня по доминирующей категории.
- История всех записей.
- Достижения.
- Финальный экран на 100% и демо-подарок для друга.
- Скриншот исходной идеи Threads на главной странице.
- Автор приложения: [Arina Svirydava](https://www.linkedin.com/in/arina-svirydava-221761172/). Идея: @redflagofff.
- Полностью локальное хранение в IndexedDB.
- Запрос persistent storage у браузера, когда он доступен.
- Экспорт всей локальной базы в JSON и импорт обратно.
- PWA-установка и офлайн-кэш.
- Никакого backend, аккаунтов, Supabase, API-ключей и `.env`.

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Vite покажет локальный адрес. Для проверки на телефоне в одной Wi-Fi сети откройте сетевой адрес, который напечатает Vite.

## Production build

```bash
npm run build
npm run preview
```

После сборки готовый сайт находится в папке `dist/`.

## Netlify

В проект уже добавлен `netlify.toml`.

1. Загрузить репозиторий на GitHub или вручную отдать проект Netlify.
2. Build command: `npm run build`.
3. Publish directory: `dist`.

## Где хранятся данные

Все пользовательские данные сохраняются в браузерном IndexedDB с именем `grekhometr-db`.

Закрытие вкладки, браузера или перезапуск телефона данные не сбрасывает. Данные можно потерять, если пользователь вручную очистит данные сайта, удалит хранилище браузера или использует приватный режим. Для переноса на другой телефон предусмотрены `Экспортировать душу` и `Восстановить душу`.

## Структура ассетов

```text
public/assets/
  backgrounds/     10 фонов
  characters/      10 boy + 10 girl
  buttons/         декоративные подложки кнопок
  circles/         9 кругов ада
  decor/           огонь, дым, облака, цепи и т.д.
  final/           слои финального экрана
  intensity/       5 уровней интенсивности
  redemption/      слои искупления
  sin-icons/       WebP-иконки категорий
  origin/          скриншот исходной идеи
  icons/           PWA-иконки
```

## Важная деталь по фонам

В загруженном наборе визуальная яркость файлов `background-level-04` и `background-level-07` не совпадала с ожидаемым порядком от светлого к тёмному. Поэтому приложение не переименовывает исходники, а использует внутреннюю карту порядка в `src/data/copy.ts`. Если позже перегенерировать эти фоны в строгой последовательности, можно вернуть отображение 1:1.

## Основные файлы

- `src/store.ts` - расчёты, локальная база и действия.
- `src/db/index.ts` - IndexedDB.
- `src/data/seedSins.ts` - стартовый каталог грехов.
- `src/data/categories.ts` - категории и привязка к кругам.
- `src/data/prayers.ts` - молитвы.
- `src/components/HomeView.vue` - главная.
- `src/components/AddSinModal.vue` - создание и совершение греха.
- `src/components/RedeemModal.vue` - искупление.
- `src/components/HellView.vue` - круги ада и достижения.
- `src/components/SettingsView.vue` - персонаж, каталог, импорт/экспорт и сброс.

## Ограничения

Грехометр сатирический. Привязка категорий к кругам ада сделана как игровая механика по мотивам Данте и не является богословской классификацией.

Скидка `HELLFRIEND13` на финальном экране сейчас является интерфейсной демо-наградой. Реальную Premium-оплату невозможно провести без backend или внешней платёжной системы.
